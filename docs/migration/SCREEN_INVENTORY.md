# OpenBoxes GSP Screen Inventory (Phase 0.4 — Dead-Screen Audit)

Static-analysis audit of every GSP under `grails-app/views/`. Generated by
[`docs/migration/scripts/audit_screens.py`](scripts/audit_screens.py) and
[`docs/migration/scripts/build_inventory_md.py`](scripts/build_inventory_md.py);
raw data in [`docs/migration/scripts/screen_inventory.json`](scripts/screen_inventory.json).

## Methodology

Each GSP was classified using the following evidence sources:

- **Controller actions** (Grails convention `views/<controller>/<action>.gsp`), including old closure-style and webflow (`*Flow`) state views
- **URL mappings** (`grails-app/controllers/org/pih/warehouse/UrlMappings.groovy`)
- **Explicit `render(view:)` / `render(template:)`** calls in controllers, services, and taglibs (including template paths passed as plain string arguments)
- **Menu / navigation references** (`grails-app/conf/runtime.groovy` megamenu, `_menu.gsp`, layouts)
- **`g:link` / `g:include` / redirect references** across all GSPs and Groovy sources
- **Template inclusion graph** (`g:render template=`, `tmpl.`, `g:applyLayout`, layout `meta` tags) resolved to a fixpoint — a `_template.gsp` is only counted live if transitively included by a live page
- **React SPA routes** (`src/js/components/Router.jsx`) to detect screens superseded by the SPA

Classifications:

| Classification | Meaning |
|---|---|
| **LIVE** | User-reachable screen (routed controller action, menu link, explicit render, or link reference) |
| **TEMPLATE** | Partial/layout included (transitively) by a live page |
| **SUPERSEDED** | GSP still exists but the route is served by the React SPA |
| **DEAD** | No route, menu, render, or include reference found |

## Summary

| Classification | Count |
|---|---|
| LIVE | 274 |
| TEMPLATE | 231 |
| SUPERSEDED | 7 |
| DEAD | 104 |
| **Total** | **616** |

The migration-relevant surface is **274 live screens** (plus 231 supporting templates that are included by them). 104 GSPs have no discoverable references and are candidates for deletion; 7 have already been replaced by React SPA routes.

> Note: the pre-audit expectation was ~350–450 live screens of 616. The evidence shows fewer standalone LIVE screens (many GSPs are `_partial` templates rather than full screens); LIVE + TEMPLATE together = 505 GSPs of user-facing surface.
